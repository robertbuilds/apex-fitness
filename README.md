# Apex Fitness | Reach Your Peak

Modern **Gym Website** designed for a premium fitness facility.
The website presents memberships, coaching staff, and contact information with smooth scroll animations and a fully responsive layout.

## Features

* 🏋️ Full responsive design (desktop, tablet, mobile)
* ✨ Scroll-triggered reveal animations
* 💳 Membership cards with expandable details
* 👥 Team section with hover social overlays
* ❓ Interactive FAQ accordion
* 📬 Contact form with service selection
* 🍔 Animated hamburger menu for mobile
* 🔝 Scroll to top button
* 🌙 Dark glassmorphism navbar

## Technologies

* HTML
* CSS
* JavaScript
* Font Awesome
* Google Fonts (Montserrat)

## Structure

```
/images        → Photos, logo, and background assets
index.html     → Main page structure
style.css      → Styling and responsive design
script.js      → Animations and interactions
```

## Sections

* **Hero** — Full-screen landing with CTA buttons
* **About** — Story, coaching philosophy, and Apex Standards
* **Memberships** — Principal plans + additional passes
* **Our Team** — Coach cards with specializations
* **FAQ** — Common questions with accordion answers
* **Contact** — Form + contact info + WhatsApp support
